# Streamlit Hello World

This project is a minimal Streamlit app for a single-page greeting interaction.
It is intentionally small, easy to run locally, and designed for quick iteration.

## Setup
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

## Run
streamlit run app.py

## Develop
Keep the implementation minimal and clear. Update app.py for the UI behavior,
adjust dependencies in requirements.txt only when needed, and validate the button
interaction locally before committing changes.
