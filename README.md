# Streamlit Hello World

This project is a minimal Python app built with Streamlit. It renders a small UI with a button that displays Hello World when pressed.

## Build
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

## Run
streamlit run app.py

## Develop
Keep the implementation small and focused. Update the app entry point and supporting files as needed, and validate the interaction locally before committing changes.
